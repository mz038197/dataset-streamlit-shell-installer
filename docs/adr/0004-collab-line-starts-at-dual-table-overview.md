# 協作線以雙表概覽為起點，取消單表上傳頁

課堂主線已是「欄位與資料整合（雙表）→ 清理」，獨立「資料上傳與預覽」頁會搶走側欄注意力，且單表上傳無法承載鍵名不一致、left join 等教學陷阱。定案：刪除該頁與單表 CSV uploader；App 預設落地仍為總覽；無 Working 的空狀態一律導向「欄位與資料整合」。進 Original／Working 的寫入路徑已改由 ADR-0010（本頁上 Agent 執行資料整合）取代「資料整合頁套用合併按鈕」。

**Considered Options**: 把 uploader 塞進總覽／概覽摺疊；或以 Agent／MCP 下載取代上傳。前者仍與雙表搶入口，後者不適合當離線課堂預設。選定刪入口、保留總覽地圖。

**Consequences**: 自備單表 CSV 進清理線暫不支援；日後若需要應另開明確「進階／自備資料」入口，不要把 uploader 默默掛回側欄第一項。
