# 線性回歸訓練微步驟加樣本運算表

梯度演算板只演示參數級 w／b／∂J／Δ，無法指著逐筆講 ŷ 與 Cost。決定在訓練左欄、演算板下方另設「樣本運算表」：僅「預測 ŷ」「算 Cost J」兩微步顯示；`head(5)`；欄名用 ŷ／y／error／error²（Cost 步才攤誤差）；整批純量 J 一行顯示、不逐列叫 J。兩階段特徵訓練皆 Z-score，表上 x 為同一組縮放輸入並註記已縮放；單變量右圖散點仍用原始尺度、線以 scaler 映射，避免「原始 x×w」畫歪。不併入梯度演算板標題；不取代輸出區「預測與誤差」表之時點。

**Considered Options**: 併入梯度演算板同一標題（拒：語義過載）；四微步都掛表（拒：梯度／更新步搶視線）；逐列欄位名 J（拒：與整批 Cost 混淆）；僅多變量縮放、單變量表不註記（拒：兩階段故事不一致）；單變量圖改純 Z 橫軸（拒：原單位直覺變弱）。

**Consequences**: 單變量訓練須帶 scaler（與多變量對齊）；樣本表／frame 組裝宜落在可單測純函式；繪圖須知悉 scaler，不可假設 w 直接乘原始 x。
