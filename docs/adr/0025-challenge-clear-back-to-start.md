# 清除回起點會還原該公司空殼，換公司不會

ADR-0014 定更換挑戰公司不刪檔、不還原專案展示空殼，以便對照兩間公司。同一間公司要把進度打回 Challenge 起點資料時，若只刪 CSV 而留下已填的模型區，下一次切分會對到已不存在的欄。定案：專案展示「清除回起點」經清除回起點確認後，只動目前公司：刪工作／訓練／測試與該公司區函式形狀的 Challenge UI 快照，live UI 還原空殼；舊整頁檔不刪、也不因此畫鈕（ADR-0028）。起點與其他公司、Challenge Agent session 不動。換公司規則不變。

**Considered Options**：只刪 train／test、留下 working；刪 CSV 但留 UI 快照；兩個確認視窗。前兩項讓「回到起點」名實不符，或留下對錯資料的模型程式。

**Consequences**：空殼多一條載入路徑：該公司快照被清除回起點刪掉之後。Agent 仍不得自行還原空殼。雙表線「清除回雙表起點」沒有確認視窗，挑戰線這顆鈕有。
