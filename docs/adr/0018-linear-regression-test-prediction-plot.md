# 線性回歸訓練畫面加測試集預測對照

ADR 0015 把訓練畫面收成回歸線與 Cost。切分槽進來後，測試只剩 Cost 數字，學生看不到 holdout 點怎麼靠近對角線。決定在雙圖下方加「測試集預測對照」：只畫測試集，橫軸實際、縱軸預測，y=x 虛線，軸限鎖在實際 y（必要時含 0）。開訓後與回歸線、Cost 逐幀一起更新。左圖改為訓練點實心、測試點淡底分色，測試點不當左圖主秀。多變量左圖是全表實際 vs 預測，不是 2D 回歸線。本決策補在 ADR 0015／0017 上。

**Considered Options**: 只在動畫播完才出下圖（拒：三張圖不同步）；下圖也畫訓練點（拒：與左圖重複）；橫軸 ŷ 縱軸 y（拒：與實際 vs 預測的閱讀方向相反）；軸限跟著 ŷ 跑（拒：α 炸掉時對角線會被縮成縫）。
