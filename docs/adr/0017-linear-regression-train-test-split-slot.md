# 線性回歸加訓練／測試切分槽

線性回歸從五格改為六格：輸入資料之後加「訓練／測試切分」。學生在對話決定訓練集整數占比 1–99，Agent 寫入；頁上無旋鈕。進頁尚未選擇，組模型預設不寫此槽。訓練只吃訓練集，特徵縮放只 fit 訓練集；動畫與結果同時更新訓練 Cost 與測試 Cost，Cost 圖兩條線。不寫檔，也不做驗證集。本決策補在 ADR 0015 的五格契約上。

**Considered Options**: 頁上 slider／％框（拒：右欄沒決策可做，且 ADR 0015 已拒左欄改選擇）；進頁或組模型預設 80／20（拒：這格就不是決策）；五檔比例（拒：課堂要自訂％）；靜默 80／20 像決策樹／CNN（拒：這頁要學生決定）；切分寫進模型程式碼預覽（拒：預覽不是訓練腳本）。
