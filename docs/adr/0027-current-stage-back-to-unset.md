# 打回尚未選擇只動目前學習階段

決策槽一旦寫入，只能改目前選擇，無法回到尚未選擇；過早說「其餘用預設」後沒有重走組模型儀式的路。定案：學生對資料 Agent 說「打回尚未選擇」或「這個學習階段打回尚未選擇」，當輪把目前 radio 那一側除輸入資料外寫回尚未選擇（含鎖定格與 α／epochs；邏輯迴歸階段「多項式與 λ」的 λ 隨損失格）。兩頁同一契約。本決策補在 ADR 0026 的寫入契約上。

**Considered Options**: 只保留改值（拒：重整頁面也救不回 JSON）；第一版就做單格打回（拒：與改目前選擇重疊）；頁上加鈕或確認視窗（拒：破選擇明細只讀）；點名即可打回沒在看的階段或一次兩側（拒：偷改另一側）；含糊「清掉／重來」也寫入（拒：對偶組模型只列不寫）；打回時重開關卡或清對話（拒：關卡與組模型是兩道門）。

**Consequences**: 改一格的值仍走改目前選擇。host 必須承認整階段打回；寫入用該階段 `unset: true`，partial merge 忽略 null，不得靠寫 null 冒充單格打回。同一檔兩階段都帶 unset 則都不套用。輸入資料始終完成。該階段訓練結果作廢；訓練前預測與對話不動。
