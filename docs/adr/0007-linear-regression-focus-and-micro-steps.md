# 線性回歸改焦點單欄與訓練微步驟

三欄並排在內容區雙欄殼內難以閱讀，且無法演示「梯度如何更新 w」。決定廢除 ADR 0005 的「下方三欄」版面：平時以「目前查看」焦點單欄對應三粗節點；訓練時改左梯度演算板／右圖，並在粗骨架下加四格訓練微步驟條（預測 ŷ → 算 Cost J → 算梯度 → 更新參數），每一抽樣 iteration 跑完四微步。單變量直式板、多變量表格（b 表尾）；預設自動播放，可開逐步模式。ADR 0005 的自研 SVG 三節點粗骨架仍保留；僅其「下方三欄掛內容」被本決策取代。

**Considered Options**: 維持三欄只加字幕（拒：仍擠且無梯度演示）；把微步驟升成頂部多節點（拒：靜態導覽過載）；僅單變量完整板（拒：兩階段應同一規則）。

**Consequences**: 流程／微步驟／演算板字串與 frame 組裝宜落在可單測純函式；UI 負責焦點切換、訓練雙欄與逐步 session 狀態。
