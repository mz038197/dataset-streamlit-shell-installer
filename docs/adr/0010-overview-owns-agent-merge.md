# 資料整合併入「欄位與資料整合」頁，由 Agent 寫入而非套用按鈕

學生要在同一頁邊看雙表邊請 Agent 改鍵名、再合併；獨立「資料整合」頁加上「套用合併並寫入工作資料」會把表與操作拆開。定案：側欄只留「欄位與資料整合」（舊名「欄位與資料概覽」）；拿掉套用按鈕與 join 表單；內建雙表教材只讀，合併前只准 Agent 把航程表鍵名寫進雙表工作副本；訓練前預測（資料整合）硬鎖合併寫入（不鎖改名）；解鎖後 Agent 可以 left 或 inner 一次寫入 Original 與 Working（此為 Agent 寫 Original 的唯一例外）。此寫入路徑取代 ADR-0004 的「唯一課堂路徑為資料整合套用合併」；0004 其餘（刪單表上傳、落地總覽、空狀態導向本頁）仍有效。

**Considered Options**: 兩頁並存只把表單疊進本頁；選對 join 就自動寫檔、不經 Agent。前者仍比現在更擠，後者對不上「請 Agent 改」。選定單一「欄位與資料整合」頁＋Agent 兩步（先改鍵名、再合併）。

**Consequences**: host 必須拒絕未解鎖／未對齊鍵的合併，以及合併前對副本的其他清理；合併前重整／重置文案不得借用 Working／Original；成功合併後刪雙表工作副本。
