# 邏輯迴歸六槽打包、測試集機率對照與下載程式碼

第三圖已由 ADR 0022 改為測試集混淆矩陣；六槽、λ 掛損失、下載 `l2(λ)` 仍成立。

邏輯迴歸維持六格，不另開正則化槽。φ 鎖定在階段「多項式與 λ」的輸入資料選擇明細（degree=6，不可改）。λ 掛在損失函數：階段1 框上只寫對數損失，階段2 必須寫入 λ，「組模型」預設 λ=0.01。第三圖原為測試集機率對照，已由 ADR 0022 改為測試集混淆矩陣。六槽齊即可給該階段模型下載程式碼，契約與線性回歸相同；階段2 的 zip 含 φ，並以 `kernel_regularizer=l2(λ)` 寫入 λ，註明與課堂 λ/(2m) 係數可能不同。不改寫成 numpy GD，也不准 zip 拿掉 λ。

**Considered Options**: 第七格專放 λ（拒：階段1 空格或假鎖 λ=0，列寬與線性回歸不一致）；兩階段列不同（拒：同一頁兩套格式）；不做第三圖（拒：threshold 只剩表在跳）；第三圖沿用測試集預測對照（拒：0/1 vs 機率不是 y=x 那條故事）；下載改寫 numpy GD 求數字一致（拒：與預覽 Sequential 脫節）；zip 拿掉 λ（拒：階段2 主菜沒帶走）。
