# 課程包加裝在 AI Lab 框架上，課程包之間不共用程式

學生第一次安裝殼層時只拿到 AI Lab 框架（總覽、資料 Agent 欄、側欄品牌列、語音設定），之後上到哪一段才 `add` 哪個課程包；一個課程包對應一個側欄分段，Data Science 課程包也不例外。過去整包安裝會讓剛上資料整理的學生先下載 TensorFlow、PyTorch、ultralytics，側欄也擠滿還沒教的頁。

依賴方向只有一條：課程包可以 import AI Lab 框架，框架不 import 任何課程包、也不讀 Working；課程包之間不互相 import。兩個課程包需要同樣的程式（如專案展示用的 regression／classification、深度學習與電腦視覺共用的 TensorFlow 執行設定、PCA 用的整理線程式）時，各帶一份獨立副本，之後各改各的。

**Considered Options**：同一檔登記在多個課程包下、裝任一個就複製；被多包共用的檔一律歸框架；各帶副本。前者讓一包的修改悄悄影響另一包；中者讓框架長出課程內容。選定各帶副本，接受重複程式碼換取課程包能獨立演進（例如專案展示之後可能換做法）。

**Consequences**：修 bug 時要檢查其他課程包是否有同名副本。降維分析沒有 Working 時只提示先加裝 Data Science 課程包，不自動加裝。不相容舊安裝：學生一律以新版重新安裝；沒有安裝紀錄時 `--update` 直接報錯，提示用 `--force` 重裝，不猜測裝了哪些課程包。
