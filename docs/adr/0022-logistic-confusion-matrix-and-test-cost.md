# 邏輯迴歸第三圖改測試集混淆矩陣，測試 Cost 不含 λ

ADR 0020 的第三圖是測試集機率對照。0/1 對機率看起來像兩條直柱，讀不成線性回歸那條 y=x 故事。改成測試集混淆矩陣；分類 threshold 改這張 2×2 與表／正確率，左圖邊界仍鎖 ŷ=0.5。Agent 快照給與動畫同一套約 80 點訓練／測試 Cost 曲線、四格計數與兩筆正確率，禁止說看不到測試 Cost。階段「多項式與 λ」的訓練 Cost 仍含課堂 λ/(2m)||w||²；測試 Cost 只算對數損失。下載程式碼的 `l2(λ)` 註記不變。

**Considered Options**: 留機率對照只加圖註（拒：橫軸仍是兩條直柱）；仿線性回歸 y=x（拒：0/1 vs 機率就是現況）；錯點疊回左圖（拒：threshold 會跟邊界鎖 ŷ=0.5 打架）；測試 Cost 也加 λ 且用 m_test（拒：m 不同會髒過擬合比較）；Agent 塞完整 10000 點（拒：每輪 snapshot 過肥）。
