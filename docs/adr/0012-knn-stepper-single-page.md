# K-近鄰分類改為單頁逐步四拍、不自動播

自動 `sleep` 播放 3 個查詢點讓學生看不見「點進來 → 比距離 → 取 k → 投票」；兩學習階段又把 k／尺度跟這套儀式拆開。決定取消兩階段與尺度陷阱主路徑：關卡只留實例型與多數決，解鎖後才出現奇數 k slider；「開始預測演示」只鎖定 k 並 fit 鄰居池；「下一步」每點四拍；3 筆逐步期間不畫決策邊界。放棄對齊線性回歸的「預設自動播＋逐步模式」，以及把 k／尺度當第二階段主菜。

**Considered Options**: 只加逐步模式、仍保留兩階段與自動播（拒：不友善根因仍在，且兩階段與儀式搶主秀）；演示改成 k=1 只找最近一點（拒：多數決關卡架空）；逐步期間保留決策邊界（拒：分類答案劇透）。

**Consequences**: 本頁主路徑只用 `knn_blobs_80.csv`、標準化固定開；`knn_scale_trap_80.csv` 不再是學生頁資料。Plotly click 仍僅 3 筆走完後加演（ADR 0001 仍成立）。改 k 須重按「開始預測演示」。
