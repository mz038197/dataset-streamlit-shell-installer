# 測試集混淆矩陣下帶 precision／recall／F1

測試集混淆矩陣只給四格計數，學生看不到 precision、recall、F1。決定在矩陣正下方帶這三個數：以 y=1 為正類、英文術語、百分比一位小數、無法計算顯示 —（不填 0）。開訓後隨矩陣逐幀更新；分類 threshold 改這三數。資料 Agent 快照與模型下載程式碼都帶；快照在 — 時附原因。不印公式、不報訓練集、不加關卡。

**Considered Options**: y=0 與 y=1 各一組（拒：六個數字學生不知看哪排）；macro 平均（拒：把 2×2 平均掉）；主詞用精確率／召回率（拒：跟正確率只差一字）；圖上印公式（拒：擠掉計數，且 TP／FN 與格子命名打架）；sklearn `zero_division=0`（拒：沒預測出正類被說成 precision=0）；0–1 小數（拒：同頁正確率已是百分比）；只在訓完才出現（拒：這三數是矩陣的衍生）；只在頁上顯示（拒：Agent 又會說看不到）。
