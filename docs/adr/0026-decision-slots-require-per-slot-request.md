# 決策槽完成要學生對該格要求，組模型不再一次塞預設

ADR 0015／0017／0020／0021 把「組模型」當一次寫入 Z分數正規化、鎖定種類、α／epochs（邏輯迴歸階段2 另含 λ=0.01）的口令，切分另寫。課堂上只定訓練／測試切分占比時，Agent 仍把其餘格寫成完成。定案：其餘各格只在學生對該格提出要求後才寫入。只說組模型則列出剩餘格與可寫入的值，當輪不寫。只講切分占比只寫切分。同一句「其餘／剩下用預設」或確認已列出的格，才寫被涵蓋的格，回覆須點名寫入值。鎖定格由 Agent 講明鎖定值、學生確認後才完成。兩頁主教學欄 caption 改為討論各格再寫入。本決策修正上述 ADR 的組模型預設寫入。

**Considered Options**: 切分後自動組其餘格（拒：切分變成組模型觸發器）；拆掉組模型、逐格必問且學生必須講出鎖定值（拒：要背 Dense(1, linear)）；進頁就把鎖定格變綠（拒：鎖定格變裝飾）。

**Consequences**: host 不再指示組模型寫入預設 batch。Z分數、課堂 α／epochs、λ=0.01 仍是建議，不是未要求就寫入的目前選擇。寫回仍是 partial merge；一次可寫多格，但必須是學生要求過的格。契約靠 host 與對話，程式不拒絕同一次 JSON 寫多格。
