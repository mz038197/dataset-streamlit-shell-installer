# 邏輯迴歸改決策槽與訓練動畫

課堂上邏輯迴歸仍走教學流程圖、目前查看與訓練微步驟，與已改決策槽的線性回歸不是同一儀式。決定本頁改為決策槽列、資料 Agent 寫入決策槽狀態與訓練請求、開訓走訓練動畫；廢止教學流程圖、目前查看、訓練微步驟、梯度演算板、樣本運算表與頁上 α／epochs／λ 旋鈕。學習階段仍為線性邊界／多項式與 λ。兩階段都加訓練／測試切分。分類 threshold、Sigmoid 函數視覺化、φ 與 λ、決策邊界／contour、訓後 y／ŷ／predicted_class 表都留下；threshold 不是決策槽，表改吃測試集。本決策修正 ADR 0015「邏輯迴歸仍走舊教學流程圖，不在此列」。

**Considered Options**: 只改長相、骨架不動（拒：變成第三套規則）；看起來像槽但仍留目前查看與微步驟（拒：兩套導覽叠在同一頁）。
