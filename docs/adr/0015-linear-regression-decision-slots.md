# 線性回歸改決策槽與 Agent 寫入

課堂上線性回歸頁變成旁觀：學生看微步驟與梯度表，右欄 Agent 只能給關卡線索。決定取代同一頁：主教學欄頂部改決策槽列，資料 Agent 欄寫入決策槽狀態與訓練請求；訓練只留回歸線與 Cost。廢止三節點 SVG、目前查看、訓練微步驟、梯度演算板、樣本運算表。特徵縮放改為課堂四選一（預設 Z分數正規化），不再兩階段皆鎖 Z-score。本決策取代 ADR 0005（本頁 SVG 骨架）、0007（焦點單欄與微步驟）、0008（樣本運算表）。邏輯迴歸仍走舊教學流程圖，不在此列。

**Considered Options**: 另開新頁留舊看步驟線（拒：兩套回歸課）；把四種縮放只當口頭對照、訓練仍永遠 Z-score（拒：框上公式與實際訓練會對不上）；抄類神經網路自動實驗迴圈（拒：α／epochs 空間太小，學生又變觀眾）；左欄下拉改選擇（拒：右欄互動會掉）。

**Consequences**: 決策槽狀態／訓練請求／模型程式碼預覽對齊類神經網路的寫檔協議，但不做自動連跑。改該階段決策槽狀態即作廢該階段訓練結果。散點維持原尺度、線映回原尺度（ADR 0008 這條圖表取捨仍成立，樣本表本身不成立）。
