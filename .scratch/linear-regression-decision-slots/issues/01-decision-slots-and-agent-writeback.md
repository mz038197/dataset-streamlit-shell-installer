# 01 — 線性回歸決策槽與 Agent 寫入

**What to build:** 同一頁線性回歸改成決策槽列。輸入資料進頁即為該階段內建表；其餘尚未選擇。跟 Agent 組模型後寫入 Z分數正規化、MSE、SGD 等，不自動開訓。完成綠框、未完成紅框，框上不寫尚未選擇。點槽看只讀選擇明細（輸入資料含列數與前 10 列；特徵縮放帶課堂四種公式）。可請 Agent 改特徵縮放或 α／epochs；鎖定槽種類拒改。關卡沿用舊兩題，過關且槽齊後，按鈕或訓練請求走同一套訓練動畫（只有回歸線與 Cost）。改該階段決策槽狀態即作廢該階段訓練結果。兩學習階段各一份狀態與結果。沒有三節點 SVG、目前查看、微步驟、演算板、樣本表、頁頂 dataset metrics。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 進頁輸入資料已是該階段內建表（綠框）；其餘四槽未完成（紅框、只留槽名）；沒有套用預設按鈕
- [x] 點槽展開／再點收起只讀選擇明細；輸入資料含列數與訓練欄前 10 列；特徵縮放明細含公式、範圍、條件
- [x] 頁頂不掛資料列數 metric；框上不用尚未選擇／檢視中／primary 當完成狀態
- [x] 舊骨架不在：三節點 SVG、目前查看、訓練微步驟、梯度演算板、樣本運算表、逐步模式
- [x] 請 Agent 組模型寫入預設決策槽狀態（Z分數正規化＋鎖定槽現況），模型程式碼預覽一致，且不自動開訓
- [x] 請 Agent 改四種特徵縮放之一或 α／epochs，框、明細、預覽同步；改資料來源／層／損失／優化器種類被拒絕
- [x] 正規化（除以最大）在訓練特徵有負值時不能開訓，並說明原因
- [x] 訓練前預測仍是舊兩題；未過關或槽未齊時按鈕與訓練請求皆鎖；Agent 不准代填、不准 exec 假裝訓完
- [x] 過關且槽齊後，開始訓練與訓練請求播同一套畫面：散點原尺度、線映回、Cost、一行狀態；決策槽列訓練中可見、框上有目前選擇，播完前不可點
- [x] 改該階段決策槽狀態立刻清掉該階段訓練結果；另一學習階段不受影響
- [x] 兩學習階段各有決策槽狀態與訓練結果；切走再回來還在
- [x] 邏輯迴歸頁未改成決策槽列
