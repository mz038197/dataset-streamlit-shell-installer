# 01 — 線性回歸決策槽與 Agent 寫入

**What to build:** 同一頁線性回歸改成決策槽列。進頁尚未選擇；跟 Agent 組模型後寫入預設決策槽狀態（Z分數正規化、MSE、SGD 等鎖定槽現況），不自動開訓。點槽看只讀選擇明細（特徵縮放帶課堂四種公式）。可請 Agent 改特徵縮放或 α／epochs；鎖定槽種類拒改。關卡沿用舊兩題，過關且槽齊後，按鈕或訓練請求走同一套乾淨訓練（只有回歸線與 Cost）。改該階段決策槽狀態即作廢該階段訓練結果。兩學習階段各一份狀態與結果。沒有三節點 SVG、目前查看、微步驟、演算板、樣本表。

**Blocked by:** None — can start immediately
