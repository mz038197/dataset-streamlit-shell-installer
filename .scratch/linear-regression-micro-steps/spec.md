# 線性回歸焦點單欄與訓練微步驟

## Requirements（已落地／歷史）

1. 廢除流程圖下方三欄並排；平時以「目前查看」焦點單欄（輸入資料／回歸模型／輸出呈現），預設回歸模型；SVG 節點不可點。
2. 頂部粗骨架仍為三節點 SVG。
3. 開始訓練後：左梯度演算板、右圖；主流程圖下顯示四格訓練微步驟條：預測 ŷ → 算 Cost J → 算梯度 → 更新參數。
4. 每一動畫抽樣 iteration 跑完四微步。
5. 單變量直式板（w 與 b 同等完整）；多變量表格（b 表尾完整）。
6. 預設自動播放；可開「逐步模式」＋「下一步」。
7. 播完自動切到「輸出呈現」焦點。
8. 兩學習階段都做完整梯度板。
9. 更新 CONTEXT；新 ADR 0007 取代 0005 的三欄段。

## 樣本運算表（grilling 共識；已實作）

10. 與梯度演算板分立（不併入其標題）；置於左欄演算板**下方**。
11. 僅「預測 ŷ」「算 Cost J」兩微步顯示；算梯度／更新參數不顯示。
12. 固定訓練資料前 5 筆（`head(5)`）；兩學習階段同一規則。
13. 欄名教學符號：預測步為各輸入 x＋`ŷ`＋`y`；Cost 步再加 `error`、`error²`，並以一行顯示整批純量 Cost J（非逐列 J）。
14. 單變量一欄 x；多變量各特徵一欄攤開。
15. 兩階段訓練特徵皆 Z-score；表上 x 皆為縮放後輸入，且**註記已縮放**。
16. 單變量右圖：散點原始尺度；回歸線以 scaler 正確映射（不可原始 x×w 硬畫）。
17. ADR 0008 記錄分立樣本運算表與上述縮放／圖表取捨。
