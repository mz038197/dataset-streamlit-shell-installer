# 線性回歸焦點單欄與訓練微步驟

## Requirements

1. 廢除流程圖下方三欄並排；平時以「目前查看」焦點單欄（輸入資料／回歸模型／輸出呈現），預設回歸模型；SVG 節點不可點。
2. 頂部粗骨架仍為三節點 SVG。
3. 開始訓練後：左梯度演算板、右圖；主流程圖下顯示四格訓練微步驟條：預測 ŷ → 算 Cost J → 算梯度 → 更新參數。
4. 每一動畫抽樣 iteration 跑完四微步。
5. 單變量直式板（w 與 b 同等完整）；多變量表格（b 表尾完整）。
6. 預設自動播放；可開「逐步模式」＋「下一步」。
7. 播完自動切到「輸出呈現」焦點。
8. 兩學習階段都做完整梯度板。
9. 更新 CONTEXT；新 ADR 0007 取代 0005 的三欄段。
